# 卒業制作 チームページ

タスク・スケジュール(ガントチャート)・メンバー表を管理できるWebサイトです。
サーバーは持たず、ブラウザから直接Firebase(Firestore)と通信する構成なので、
GitHub Pagesにファイルを置くだけで常時アクセス可能なサイトになります。

## セットアップ手順(初回のみ)

### 1. Firebaseプロジェクトを作成

1. https://console.firebase.google.com にアクセスし、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 好きなプロジェクト名を入力(Google Analyticsは無効でOK)
3. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
   - モードは「本番環境モード」でOK(あとでルールを上書きします)
   - ロケーションはどこでも構いません(`asia-northeast1` などが近くて安心)
4. 左メニュー「構築」→「Authentication」→「Sign-in method」タブ→「匿名」を有効化
   (メンバーがパスワード不要でアプリを使えるようにするためのものです)

### 2. Webアプリを登録し、設定値を取得

1. プロジェクトのトップ画面(歯車アイコン→「プロジェクトの設定」)→「マイアプリ」→
   `</>`(ウェブ)アイコンをクリックしてアプリを登録
2. 表示される `firebaseConfig` オブジェクトの中身をコピー
3. [docs/js/firebaseClient.js](docs/js/firebaseClient.js) を開き、`firebaseConfig` の
   プレースホルダー(`YOUR_API_KEY` など)を実際の値に置き換えて保存

### 3. セキュリティルールを設定

1. Firebaseコンソール →「Firestore Database」→「ルール」タブ
2. [firestore.rules](firestore.rules) の内容をそのまま貼り付けて「公開」

### 4. 既存データの移行(以前MongoDBを使っていた場合のみ)

1. プロジェクト直下に `.env` を作成し、以前使っていた `MONGODB_URI` を設定
2. Firebaseコンソール →「プロジェクトの設定」→「サービスアカウント」→
   「新しい秘密鍵の生成」でJSONファイルをダウンロードし、プロジェクト直下に
   `serviceAccountKey.json` として保存(このファイルは`.gitignore`済みで、
   GitHubには絶対にpushされません)
3. 以下を実行

   ```
   npm install
   npm run migrate
   ```

移行が不要な場合は、後述の「初回セットアップ(アプリ側)」からそのまま始めてください。

### 5. GitHub Pagesを有効化

1. GitHubのリポジトリページ →「Settings」→ 左メニュー「Pages」
2. 「Build and deployment」の「Source」を「Deploy from a branch」に
3. 「Branch」を `main` / `/docs` に設定して「Save」
4. 数十秒〜数分待つと、ページ上部に公開URL(例:
   `https://bachi-ra.github.io/pm-app/`)が表示されます

このURLがメンバー共有用のURLになります。今後 `main` ブランチにpushするたびに
自動でサイトが更新されます。

## ローカルでの動作確認

```
npx serve docs
```

を実行し、表示されたURL(例: `http://localhost:3000`)をブラウザで開くと、
本番と同じ内容をローカルで確認できます(サーバー不要、静的ファイルを配信するだけです)。

## 初回セットアップ(アプリ側)

1. 最初にアクセスすると「最初のメンバー登録」画面が表示されるので、自分の名前・役職を
   入力して登録します(自動的に管理者になります)
2. 「メンバー」タブから残りのメンバーを追加します(名前・役職を入力。管理者権限は
   基本的にPMのみでOK)
3. 各メンバーは共有されたURLに初めてアクセスした際、自分の名前を選択します
   (パスワードは不要です)

## スマホでアプリのように使う(PWA)

このサイトはPWA(Progressive Web App)に対応しています。スマホのブラウザで
公開URLを開き、以下の操作でホーム画面にアイコンを追加すると、アプリのように
全画面で起動できます。

- **iPhone(Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android(Chrome)**: メニュー(⋮) →「アプリをインストール」または「ホーム画面に追加」

## 検索

画面右上の検索ボックスから、タスクのタイトル/カテゴリ、メモの本文、リンクのタイトルを
横断検索できます。結果をクリックすると該当のタブに移動します。

## 使い方

- **ダッシュボード**: タスクの進捗状況、直近の締切、メンバー別の進捗をひと目で確認。
  締切が近い(3日以内)未完了タスクがある状態で表示すると、通知を許可していればブラウザ通知が、
  Discord Webhookを設定していればDiscordへのリマインド投稿が(いずれも1日1回まで)行われます。
  「スケジュール」カードでは、ガントチャート/カレンダーを閲覧専用で確認できます(「ガント」
  「カレンダー」ボタンで切り替え、Excel出力・カレンダー出力(.ics)も可能)。編集操作(タスク
  追加やマイルストーン管理)は行えません。「残タスク数の推移」には、アプリを開くたびに記録
  される日次スナップショットをもとにバーンダウンチャートを表示します(導入日からの記録なので、
  しばらく使うと推移が見えてきます)。マイルストーンは目標ラインとしてグラフ上に表示されます
- **タスク一覧**: PMがタスクを登録・編集。タスクの担当は個人名ではなく「役職」で指定します
  (メンバー一覧に登録されている役職から選択、特別枠として「全員」も選べます)。自分の役職
  (または「全員」)が割り当てられたタスクは、担当メンバーなら誰でもステータス/進捗を更新可能。
  「自分の担当のみ」ボタンで、自分の役職(または「全員」)のタスクだけに絞り込めます
  - タスクにはチェックリスト(サブタスク)、優先度(高/中/低)、依存タスクを設定できます
    (すべてPMが編集モーダルから設定)
  - 依存タスクが未完了のまま先行タスクが残っていると「先行タスク未完了」の警告バッジが表示されます
  - 各タスクには「コメント」ボタンから誰でもコメントを投稿できます
    (自分のコメントは編集・削除可、PMは全コメント削除可)
  - 各タスクには「バージョン」ボタンからカットのバージョン(v1、v2…)を登録できます。
    URL・メモ・ステータス(レビュー待ち/差し戻し/承認)を管理でき、ステータスの変更は
    PMまたはそのタスクの担当者(役職一致)が可能です。フィードバックはコメント欄をご利用ください
- **スケジュール**(管理者のみ表示): タスクをガントチャートで表示。マイルストーン(中間発表・
  提出日など)も管理タブから登録すると縦線で表示されます。「ガント」「カレンダー」ボタンで
  月表示カレンダーに切り替えることもでき、締切日・マイルストーンが日付セルに表示されます。
  「Excel出力」ボタンから、表示中のガントチャート(日ごとの色分けバー)とタスク一覧を
  Excelファイル(.xlsx)として書き出せます。「カレンダー出力(.ics)」ボタンから、タスクの
  締切日とマイルストーンを.ics形式で書き出せます(Googleカレンダー・Outlook等に読み込み可能)。
  「+ 新規タスク」ボタン、またはカレンダー表示で各日付の「+」ボタンから、その場でタスクを
  新規登録できます(カレンダーの「+」から作成した場合、その日が開始日・終了日として入力
  済みの状態でフォームが開きます)。このタブ自体は管理者にのみ表示され、他のメンバーは
  ダッシュボードの「スケジュール」カードから閲覧します
- **メンバー**: メンバーと役職の一覧。PMのみ追加・編集・削除可能。PM向けの折りたたみメニュー
  から「閲覧専用URL」をコピーできます。このURLでアクセスすると、追加・編集・削除の
  ボタンがすべて非表示になり、名前を選ばずに全データを閲覧できます
  (先生など、チーム外の人に進捗を見せたい場合にご利用ください)。同じメニューから
  「データのバックアップ・復元」も行えます
  - **バックアップ**: 全コレクションのデータをJSONファイルとしてダウンロードします
  - **復元**: バックアップファイルを選択して「このファイルで上書き復元する」を押すと、
    現在のデータを削除してファイルの内容に置き換えます(確認ダイアログあり、取り消し不可)。
    **メンバー一覧だけは削除されず上書き/追加のみ**行われます(復元後に自分の管理者権限が
    消えて操作不能になるのを防ぐための仕様です。バックアップ後に増えたメンバーを消したい
    場合は、復元後に手動でメンバータブから削除してください)
- **メモ**: 誰でも投稿できる連絡・メモ掲示板。自分の投稿は編集・削除可能、PMは全投稿を削除可能。
  各メモには「既読 3/5」のように既読人数が表示され、クリックすると既読・未読のメンバー名を
  確認できます(自分の投稿は最初から既読扱い)。ナビゲーションの「メモ」タブには、自分が
  まだ読んでいないメモの件数がバッジ表示されます
- **リンク集**: Discordサーバーや共有ドライブなど、外部サイト・ツールへのリンク集。
  PMのみ追加・編集・削除可能、閲覧とクリックは全員可能。PM向けの折りたたみメニューから、
  締切リマインドを投稿するDiscord Webhook URLも設定できます
- **素材**: BGM・SE・フォント・画像などの入手元・ライセンス状況を一覧管理。追加・編集は
  全員可能、削除はPMのみ。ライセンス未確認の素材には警告バッジが表示されます
- **資料**: 絵コンテや参考画像を画像URLで登録し、ギャラリー表示するタブです。タグで絞り込み
  可能。自分がアップロードした資料は編集・削除可能、PMは全資料を削除可能
- **レンダー**: Mayaのレンダリングなど共有PCの使用状況を管理するタブです。「使用開始」フォーム
  からPC名・内容・終了予定(任意)を登録すると、使用中のPC一覧に表示されます。終了予定時刻を
  過ぎても「実行中」のままだと「予定時刻超過」の警告バッジが表示されます。登録した本人または
  PMは「完了にする」「中断にする」「削除」が可能です。完了・中断になったジョブは「履歴」に
  折りたたみ表示されます(直近10件)。ダッシュボードにも「レンダー中」の件数が表示されます

## データの保存場所・バックアップ

データはFirebase Firestoreに保存されます(`members` / `tasks` / `milestones` /
`memos` / `links` / `taskComments` / `versions` / `assets` / `references` /
`renderJobs` の10コレクション)。Firebaseコンソールの「Firestore Database」からいつでも
中身を確認・エクスポートできます。

## 権限について

- 管理者(PM): メンバー・タスク・マイルストーン・リンク集をすべて追加/編集/削除可能。
  メモは全員分を削除可能。「スケジュール」タブ(編集用)、メンバー表の閲覧専用URL発行、
  データのバックアップ・復元も管理者のみ利用可能
- 一般メンバー: 全データの閲覧、自分の役職(または「全員」)が割り当てられたタスクの
  ステータス・進捗の更新、メモの投稿・自分の投稿の編集/削除が可能。スケジュールは
  ダッシュボードのガントチャート/カレンダー(閲覧専用)で確認します

権限のチェックはブラウザ側(画面に表示するボタンの出し分け)で行っています。
このアプリは身内の小規模チームでの利用を想定した簡易的な仕組みで、パスワード認証は
行っていません。URLを知っていれば誰でもアクセスできるため、URLの共有範囲には
注意してください。
